Entry for the [make.fun bounty "The Houseplant Out-of-Office"](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047).

## The entry

> Out of office. No water since March, so I'm ignoring you back. — The fern

73 characters, one line.

## How it works

`main.py` (standard library only, deterministic) writes the entry to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set and non-empty. Run it with:

```sh
python3 main.py
```
